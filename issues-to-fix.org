Review of =README.org=, =init.el= and =early-init.el= on Emacs 31.1.
Line numbers refer to =README.org= at commit =3dfd4a4= unless stated otherwise.

* Bugs
** TODO Flycheck never turns on
=:after (flycheck-pos-tip-mode)= names a mode, not a library; the library is
=flycheck-pos-tip=. The block (including =global-flycheck-mode=) is wrapped in
=(eval-after-load 'flycheck-pos-tip-mode ...)=, which never fires (confirmed by
macroexpansion).

Fix: =:after flycheck-pos-tip=, or drop =:after= entirely. (Line ~1247)

** TODO =:config= blocks that never run because of =use-package-always-defer=
With =always-defer t=, =:config= only runs once the package loads, and nothing
loads these. Use =:defer nil=, or move the mode call to =:hook= / =:init=.

- [ ] =company-quickhelp= — =company-quickhelp-mode= never starts (line ~1321)
- [ ] =editorconfig= — never enabled. Built in since Emacs 30: replace the block
  with =(editorconfig-mode 1)= (line ~1284)
- [ ] =company-terraform= — =company-terraform-init= never runs (line ~1581)
- [ ] =flycheck-ocaml= — =flycheck-ocaml-setup= never runs (line ~1816)
- [ ] =slime-company= — =slime-company-major-modes= never set (line ~1730)
- [ ] =yasnippet= — =yas-global-mode= only starts if something else happens to
  load yasnippet first (line ~1221)
- [ ] =undo-tree= — loaded via =:defer 2= but =global-undo-tree-mode= is never
  called, so the package does nothing (line ~941)

** TODO =opam-switch-mode= hook typo
Hooks =tuareg.mode= (dot instead of dash), so it never fires.

Fix: =((tuareg-mode . opam-switch-mode))= (line ~1834)

** TODO =ocp-indent= sets variables instead of calling the setup function
The hooks set =ocp-setup-indent= and =ocp-indent-caml-mode-setup= as variables.
=ocp-setup-indent= is a function (=ocp-indent.el:144=).

Fix: =:hook ((tuareg-mode caml-mode) . ocp-setup-indent)= (line ~1828)

** TODO =treesit-fold-toogle= does not exist
=C-c f t= is bound to a misspelled command.

Fix: =treesit-fold-toggle= (line ~1208)

** TODO =uv-mode= never activates
It hooks =python-mode=, but =treesit-enabled-modes t= sends Python files to
=python-ts-mode=, which does not run =python-mode-hook=.

Fix: =:hook (python-base-mode . uv-mode-auto-activate-hook)= (line ~1518)

** TODO =vterm= overrides =C-q= globally
=:bind (("C-q" . vterm-send-next-key))= is a global binding, so =quoted-insert=
is lost in every buffer.

Fix: =:bind (:map vterm-mode-map ("C-q" . vterm-send-next-key))= (line ~1112)

** TODO =toggle-theme= stacks themes
=load-theme= enables the new theme on top of the old one, so after a toggle
both solarized variants are active.

Fix: call =(mapc #'disable-theme custom-enabled-themes)= before =load-theme=
(line ~226)

** TODO =default-tab-width= no longer exists
=(setq default-tab-width 4)= does nothing (variable is unbound in 31.1).

Fix: =(setq-default tab-width 4)= (line ~274)

** TODO =my-pretty-lambda= is wrong and unused
='((lambda-string . 955))= quotes the symbol rather than using the argument.
Nothing calls it, and the Elixir/Clojure variants are only referenced from
commented-out code.

Fix: delete all three functions (lines ~328–341)
