#+TITLE: Free key bindings
#+DATE: 2026-10-15

Keys that are free in every mode of this configuration. Bind new global
commands here and no major or minor mode will shadow them.

Only keys Emacs reserves for users are considered: =C-c= followed by a
letter, and =<f5>= to =<f9>=. Major and minor modes are not supposed to bind
these. Other prefixes may look free today, but any package can claim them.

* How this was checked
Batch Emacs: loaded =init.el=, then =require='d every installed package plus
the built-in modes the config uses. Each candidate key was looked up in
=global-map= and in every keymap variable (=*-map=) that existed afterwards.
=help-quick-use-map= and =widget-global-map= were ignored: they inherit from
=global-map=, so they only repeat global bindings.

Limits:
- Bindings added only when a mode starts aren't visible. The eglot keys are
  the known case (bound from =eglot-managed-mode-hook=), added to the table
  by hand.
- =vterm= wasn't loaded (loading it asks to compile its module), so its
  keymap wasn't checked. A terminal buffer passes most keys to the shell
  anyway.
- Re-run the check after adding packages or bindings.
